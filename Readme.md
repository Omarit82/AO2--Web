# Actividad Obligatoria 2 - Web I

## Consignas Generales:

*   Desarrollar una aplicación Web Responsive utilizando HTML, CSS , JavaScript y Bootstrap
*   Implementar las funcionalidades de Alta, Baja, Modificación y Listado de la entidad que corresponda según sea la App a construir
*   Utilizar LocalStorage para almacenar la información
*   Usar JSON como mecanismo de transferencia de datos entre los objetos JavaScript usados en al App y los almacenados en el LocalStorage
*   Tomar como referencia la App de registro de alumnos publicada en el aula en la unidad 6 y explicada en el EVS de esa unidad.

## App 04 - DNI terminados en 3 y 8 (29555208) Gestor de viajes y pasajeros.

### Una empresa de turismo desea registrar viajes y los pasajeros inscriptos.

Campos requeridos:

*   Destino (mínimo 3 caracteres)
*   Fecha del viaje
*   Duración (días)
*   Precio
*   Nombre del pasajero
*   DNI del pasajero (mínimo 7 cifras)

Requerimientos adicionales:

*   Calcular importe total (precio*cantidad de días)
*   Mostrar estadísticas: total recaudado por destino, cantidad de pasajeros por viaje.
*   Estilos condicionales para viajes (en menos de 15 días verde - 15 a 30 amarillo - +30 rojo)
*   Filtrar viajes por destino o pasajeros.

## Features

Para esta aplicación se utilizará JS con Bootstrap. La webapp esta pensada para ser mobile first.
